# Visual Parity Checklist: 시안과 나란히 비교 (SC-001)

**Purpose**: 캐릭터 시안(`docs/DashPet 캐릭터 시안.html`)과 에뮬레이터의 PetView 를 나란히 놓고 같은 느낌인지 확인한다. 기획자가 승인한다.
**Created**: 2026-11-08
**Spec**: [spec.md](../spec.md) (SC-001, FR-002~FR-005, FR-020)

사용법: 시안의 "감정 직접 보기"와 "주행 이벤트" 버튼으로 같은 입력을 만들고 에뮬레이터의 데모 컨트롤과 비교한다. 강도는 시안 기본값(0.7)과 1.0 두 가지로 본다.
항목은 구현이 끝난 뒤 채운다. 풀 모션만 시안과 비교하고, 정적 등급은 `PetPose` 정의(research R8)대로 보이는지만 확인한다.
